## About This Handbook

This repository is the **source of truth**: the canonical Markdown for every chapter, worksheet, and example lives in [`ko/`](ko/) and [`en/`](en/), and is meant to be read directly here on GitHub.

The **[Reader](https://victory3217-bot.github.io/pricing-handbook/)** (built with Astro + Starlight, see [`site/`](site/)) is a generated, sequential-reading presentation of that same content — sidebar navigation grouped by Part, in-page table of contents, Previous/Next chapter flow, and a Korean/English language switch. It is rebuilt automatically from this repository's Markdown on every push to `main`; nothing is authored directly in the Reader.

If you want to browse chapter-by-chapter with navigation, use the Reader. If you want the raw source, edit history, or to cite a specific file, use this repository.
