# CH08 P×Qty 산출 근거표

> 관련 Chapter: CH08. 정성에서 정량으로 — 유효시장 추정과 P×Qty
> 관련 MN/KM: MN07 / KM058, KM059, KM062

이 워크시트는 새 지식을 만들지 않는다. KM059의 유효시장 추정 9단계 질문과 KM062의 거래유형별 Qty 근거를 그대로 작업표 형태로 옮긴 것이다.

## A. 유효시장 추정 9단계 점검 질문 (KM059)

| 단계 | 질문 | 작성 |
| --- | --- | --- |
| 1. 아이디어·환경분석 | 어떤 아이디어에서 출발했고, 시장 환경은 어떤가? | |
| 2. 세분시장 결정·타겟팅 | 시장을 어떤 기준으로 세분화했고, 어느 세분시장을 타겟팅하는가? | |
| 3. 포지셔닝·유통·가격(가설) | 타겟 고객을 향한 포지셔닝, 유통, 가격 가설은 무엇인가? | |
| 4. 가용자원 검토(Q, D) | Quality·Delivery 관점에서 이 가설을 실행할 자원이 있는가? | |
| 5. 투입비용 검토(C) | 이 가설을 실행하는 데 드는 비용은 얼마이며, 감당 가능한가? | |
| 6. 최종 타겟팅 | QCD 검토를 반영해 최종적으로 어떤 세분시장을 타겟팅하는가? | |
| 7. 최종 포지셔닝·4P | 최종 포지셔닝과 제품·가격·유통·프로모션(4P)은 무엇인가? | |
| 8. BMC 결정 | 위 결과를 반영한 최종 비즈니스모델(BMC)은 무엇인가? | |
| 9. 유효시장 규모 추정 | 확정된 BM을 바탕으로 유효시장 규모(P×Qty)는 얼마인가? | |

> 9단계는 순서대로 한 번만 지나가는 절차가 아니다. 9단계 결과가 사업목표나 자원조건에 미치지 못하면, 해당하는 앞 단계로 돌아가 다시 채운다.

## B. 거래유형별 P×Qty 근거표 (KM062)

### B2C

| 항목 | 내용 | 작성 |
| --- | --- | --- |
| P (가격) | 제품/서비스 가격 | |
| Qty 근거 1 | 타깃고객 수 (인구/모집단 규모) | |
| Qty 근거 2 | 연간 소비량/구매빈도 | |
| Qty 산출 논리 | "얼마에 몇 명이 얼마나 자주 구매할 것인가" | |

### B2B

| 항목 | 내용 | 작성 |
| --- | --- | --- |
| P (가격) | 주문량에 따라 달라지는 단가 구조 | |
| Qty 근거 1 | 발주규모 (대량발주 여부, 고정비 구조와의 관계) | |
| Qty 근거 2 | 전방산업 생산실적 (Top-down 방식 활용 여부) | |
| 공급능력 제약 | 자체 생산능력 vs. 협업 생산 파트너를 통한 확장 가능성 | |

### B2G

| 항목 | 내용 | 작성 |
| --- | --- | --- |
| P (가격) | 장비/서비스 가격 | |
| Qty 근거 1 | 잠재 설치대상 수 | |
| Qty 근거 2 | 법령상 설치·관리 의무 여부 | |
| Qty 근거 3 | 예산항목 및 예산 규모 (집행 가능 범위) | |
| Qty 근거 4 | 접근 방식 (직접영업 vs. 파트너 채널) | |
| 제약조건 | 제도·예산이 시장규모를 규정하는 상한선인지 확인 | |

## 사용 방법

1. A표를 먼저 작성해 9단계 전체의 가설-검토-확정 흐름을 채운다.
2. 자사 거래유형(B2C/B2B/B2G)에 해당하는 B표의 섹션을 채워 Qty의 구체적 근거를 세운다.
3. A표의 9단계 결과(P×Qty)와 B표의 근거가 서로 일치하는지 확인한다.
