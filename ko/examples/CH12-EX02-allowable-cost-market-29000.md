# CH12-EX02. 시장가 29,000원이면 직접원가는 얼마까지 쓸 수 있는가

- 관련 Chapter: CH12. MODE C — 허용원가 역산
- 관련 MN/KM: MN06 / KM054

## 생각해 보기

〔실습용 가상자료〕 CH10-EX03의 상품과 같은 판매·배송 비용 구조(택배비 3,200원, 결제 수수료 실지급액의 2.8%, VAT율 10%)에서, 경쟁 제품의 실거래가가 29,000원(VAT 포함)이다. 목표 공헌이익률은 50%이고 실제 직접원가는 9,800원이다.

1. 시장가의 VAT 제외 순매출 N은 얼마인가?
2. 허용 직접원가(ADC)는 얼마인가?
3. 실제 직접원가와 허용원가의 차이(direct_cost_gap)는 얼마인가? 어떤 선택지를 검토할 수 있는가?

<details>
<summary>정답과 풀이 보기</summary>

t = 0.50, b = 0, a = 0.028, F = 3,200원, v = 0.10.

1. N = 29,000 ÷ 1.10 = 26,363.64원.
2. D = 1 − 0.50 − 0.028 × 1.10 = 0.4692, ADC = N × D − F = 26,363.64 × 0.4692 − 3,200 = 9,169.82원.
3. direct_cost_gap = 9,169.82 − 9,800 = −630.18원이다. 실제 원가가 허용원가를 약 630원 넘는다. 이 시장가격과 목표율에서는 소싱 단가 인하, 결제 수수료나 택배비 재협상, 목표율 재검토, 가격대 재검토를 검토할 수 있고, 어느 쪽을 택할지는 계산이 정하지 않는다. 허용원가는 실제 원가를 읽지 않고 계산하며, 마지막에 차이로만 비교한다.

- 무엇을 설명하는 사례인지: 시장가격이 외생적으로 정해졌을 때 원가 상한을 역산하고 실제 원가와 비교하는 target costing 계산.

</details>

출처: 표준강의안 3-1 사례 종합 실습 문제 3 (〔실습용 가상자료〕, 파이썬 검산). 계산 구조는 CH12-EX01과 같다.
