# CH13-EX03. 문제은행형 연습 — 33,000원 상품의 손익분기와 월 150개 판매 손익

- **관련 Chapter**: CH13. BEP — 손익분기점 (§10 심화)
- **관련 Tool**: BEP (`run_bep`), Volume Profit (`run_volume_profit`)
- **출처**: 표준강의안 3-1-09 (사례 종합 실습, 문제 1·4). 교육용 가상자료〔실습용 가상자료〕이며 실제 기업 데이터가 아니다. 식은 CH13 §4·§6과 같다.

## 입력값

| 항목 | 값 |
|---|---|
| 판매가 | 33,000원 (VAT 10% 포함) |
| 직접원가 | 9,800원 |
| 결제 수수료 | 실지급액(33,000원)의 2.8% |
| 택배비 | 3,200원 (1개 판매 기준) |
| 월 고정운영비(FC) | 1,200,000원 (기간 기준: 월) |
| 계획 판매량 | 월 150개 |

## 문제

1. 먼저 1개당 공헌이익(CMu)과 공헌이익률을 구하세요. (순매출은 VAT를 뺀 값이다.)
2. 월 고정운영비를 회수하는 손익분기 판매량(Q_BEP)은 몇 개인가요? 보고서에는 몇 개로 적겠습니까?
3. 월 150개를 판매하는 계획의 영업이익은 얼마인가요?
4. 안전한계(수량과 비율)는 얼마이고 어떻게 읽어야 하나요?

## 계산 과정

```
N      = 33,000 / 1.1                    = 30,000
변동비 = 33,000 × 2.8% + 3,200 = 924 + 3,200 = 4,124
CMu    = 30,000 − 9,800 − 4,124          = 16,076      (공헌이익률 16,076 / 30,000 ≈ 53.6%)
Q_BEP  = 1,200,000 / 16,076              ≈ 74.65개     (올림 75개)

operating_profit          = 16,076 × 150 − 1,200,000 = 2,411,400 − 1,200,000 = 1,211,400
margin_of_safety_quantity = 150 − 74.65             ≈ 75.35개
margin_of_safety_rate     = 75.35 / 150             ≈ 50.2%
```

## 해석

- 손익분기는 월 약 74.65개이고, 엔진은 반올림하지 않은 값을 내므로 "75개"로 올려 적는 판단은 보고 단계에서 한다(CH13 §7).
- 월 150개를 팔면 영업이익은 1,211,400원이다. 계획이 손익분기의 약 2배라서 판매량이 계획보다 약 50% 줄어도(약 74.65개까지는) 고정비를 회수한다.
- 이 해석은 150개가 팔린다는 전제 위에 있다. `planned_quantity`는 입력일 뿐 수요 예측이 아니다.
- 택배비 3,200원을 주문당 비용으로 입력하면 계산기는 주문당 1개 판매를 가정하므로, CMu에 의존하는 지표가 `ESTIMATED`로 표시되고 `ASSUMES_ONE_UNIT_PER_ORDER` 경고가 붙는다(CH13 §6). 한 주문에 2개 이상 사는 고객이 많으면 실제 영업이익은 이 값보다 크다.
- 이 문제에는 수수료·택배비 외의 판매 비용이 없으므로 공헌이익에 더 넣지 않았다. 실제 사업에서는 빠진 비용이 없는지 먼저 확인한다.
