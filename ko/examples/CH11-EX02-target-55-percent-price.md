# CH11-EX02. 공헌이익률 55%를 남기려면 얼마에 팔아야 하는가

- 관련 Chapter: CH11. MODE B — 목표가격 역산
- 관련 MN/KM: MN06 / KM046, KM047

## 생각해 보기

〔실습용 가상자료〕 CH10-EX03의 상품(직접원가 9,800원, 택배비 3,200원, 결제 수수료 실지급액의 2.8%, VAT율 10%)에서 목표 공헌이익률을 55%로 정했다. 목표율은 연습용 가정이다.

1. 분모 D = 1 − t − b − a(1+v)는 얼마인가? 0 이하가 되는가?
2. 목표 순매출 N과 목표 총지불금액 G(VAT 포함)는 얼마인가?
3. 현재 판매가 33,000원과 비교하면 어떤 결론이 나오는가? 이 가격에서 공헌이익률을 검산하시오.

<details>
<summary>정답과 풀이 보기</summary>

C = 9,800 + 3,200 = 13,000원, b = 0, a = 0.028, v = 0.10, t = 0.55.

1. D = 1 − 0.55 − 0 − 0.028 × 1.10 = 0.4192. 0보다 크므로 ERROR가 아니다.
2. N = 13,000 ÷ 0.4192 = 31,011.45원, G = N × 1.10 = 34,112.60원(약 34,113원).
3. 현재 33,000원보다 약 1,113원 높다. CH10-EX03에서 현재 공헌이익률이 53.6%였으므로 목표 55%에 미치지 못한다는 것과 같은 결론이다. 검산: 가격이 34,112.60원일 때 수수료 = 34,112.60 × 2.8% = 955.15원, 공헌이익 = 31,011.45 − 9,800 − 955.15 − 3,200 = 17,056.30원, 공헌이익률 = 17,056.30 ÷ 31,011.45 = 55.0%. 이 계산은 고객이 34,113원을 받아들일지는 말해 주지 않는다.

- 무엇을 설명하는 사례인지: MODE A의 결과를 먼저 보고 같은 비용구조에서 목표율에 필요한 가격을 역산하며, 검산으로 목표율이 다시 나오는지 확인하는 사례.

</details>
