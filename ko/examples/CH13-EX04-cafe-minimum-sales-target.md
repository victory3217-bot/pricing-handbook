# CH13-EX04. 목표 판매량 계산 — 가상 카페의 월 최소 판매 목표

- **관련 Chapter**: CH13. BEP — 손익분기점 (§10 심화)
- **관련 Tool**: 없음 (수기 계산. BEP와 같은 식 `FC / CMu`를 적용하되, 상품 믹스는 단순 가중평균으로 계산한 것이며 Harness가 정의한 계산이 아니다.)
- **출처**: 표준강의안 3-1-10 (AI 활용 원가관리·수익모델 워크숍, E구간)이 인용한 워크숍 교안의 계산 틀. 교육용 가상 카페〔실습용 가상자료〕이며 실제 사업장 숫자가 아니다.

## 입력값

| 항목 | 값 |
|---|---|
| 월 총 고정비 | 5,900,000원 |
| 원하는 월 순수익 | 500,000원 |

| 상품 | 판매가 | 1개당 변동비 |
|---|---|---|
| 커피 | 5,000원 | 2,000원 |
| 샌드위치 | 7,500원 | 3,100원 |
| 디저트 | 6,000원 | 2,100원 |

판매가는 VAT를 뺀 값으로 읽는다(워크숍 원문이 VAT를 다루지 않는다. VAT 포함가라면 먼저 VAT를 빼야 한다). 월 판매 비중은 커피 60 : 샌드위치 25 : 디저트 15로 가정한다.

## 문제

1. 상품별 1개당 실제 남는 돈(이익)은 얼마인가요?
2. 커피만 판다고 할 때, 고정비를 회수하는 월 최소 판매량과 순수익 50만 원을 더한 판매량은 얼마인가요?
3. 위 판매 비중으로 세 상품을 섞어 판다면 평균 1개당 이익과 월 최소 판매량, 상품별 수량은 얼마인가요?
4. 이 수량은 어떤 성격의 숫자인가요?

## 계산 과정

```
1개당 이익 = 판매가 − 1개당 변동비
  커피       5,000 − 2,000 = 3,000
  샌드위치   7,500 − 3,100 = 4,400
  디저트     6,000 − 2,100 = 3,900

커피만 판매
  최소 판매량           = 5,900,000 / 3,000            ≈ 1,966.7잔 (올림 1,967잔)
  순수익 포함 판매량    = (5,900,000 + 500,000) / 3,000 ≈ 2,133.3잔 (올림 2,134잔)
  순수익 포함 목표 매출 = 2,133.3 × 5,000              ≈ 10,666,667원

상품 믹스 (60 : 25 : 15)
  평균 1개당 이익 = 0.60×3,000 + 0.25×4,400 + 0.15×3,900 = 1,800 + 1,100 + 585 = 3,485
  최소 판매량     = 5,900,000 / 3,485                    ≈ 1,693개
  상품별          커피 약 1,016 / 샌드위치 약 423 / 디저트 약 254
```

## 해석

- "월 최소 판매 목표 = 월 고정비 ÷ 1개당 실제 이익"은 BEP의 `Q_BEP = FC / CMu`와 같은 식이다. 1개당 이익이 변동비만 뺀 값이므로 공헌이익에 해당한다.
- 이 수량은 생존에 필요한 최소 목표다. 순수익까지 얻으려면 순수익을 고정비에 더해 같은 식을 적용한다.
- 마진이 높은 상품의 비중이 커지면 평균 1개당 이익이 올라 필요한 수량이 줄어든다(커피만 팔 때 1,967잔, 믹스일 때 1,693개). 비중은 가정이지 예측이 아니다.
- 고정비는 판매량이 달라져도 같다고 두는 계산이다. 고정비와 변동비를 섞어 넣으면 이 식이 성립하지 않는다.
- 이 수량이 실제로 팔릴 수 있는지는 별도 문제다. 거래유형별 Qty 산정 근거(CH13 §7, KM062)로 따로 검증한다.
