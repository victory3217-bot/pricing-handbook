# CH01-EX01. 가상 카페의 월 최소 판매 목표 (총 고정비 590만 원)

- 관련 Chapter: CH01 (가격은 비즈니스모델의 결과다) §10 "소상공인의 고정비와 월 최소 판매 목표"
- 데이터 출처: 〔실습용 가상자료〕 — 표준강의안 3-1 AI 활용 원가관리·수익모델 워크숍의 연습 가정. 실제 업체 자료가 아니다.
- 주의: 이 사례는 워크숍의 단순식(1개당 이익 = 판매가 − 변동비)을 쓴다. VAT와 수수료 기준은 반영하지 않았으므로, 판매가가 VAT 포함이면 먼저 VAT를 뺀다(CH10 참고).

## 사례 데이터

가상 카페의 한 달 고정비는 다음과 같다.

| 구분 | 항목 | 금액 |
|---|---|---|
| 생활 필요 고정비 | 주거 700,000 + 식비 600,000 + 보험·의료 250,000 + 교육 300,000 + 통신 100,000 + 교통 150,000 + 기타 100,000 | 합계 (문제 1) |
| 사업 필요 고정비 | 임차료·관리비 1,200,000 + 정직원 인건비 1,800,000 + 대출이자·보험 250,000 + 통신비·공과금 300,000 + 기타 150,000 | 합계 (문제 1) |

주력 상품 세 가지의 판매가와 1개당 변동비(재료비·포장비 등)는 다음과 같다.

| 상품 | 판매가 | 1개당 변동비 |
|---|---|---|
| 커피 | 5,000원 | 2,000원 |
| 샌드위치 | 7,500원 | 3,100원 |
| 디저트 | 6,000원 | 2,100원 |

## 문제

1. 생활 필요 고정비, 사업 필요 고정비, 총 고정비는 각각 얼마인가요? 생활 필요 고정비는 총 고정비의 몇 %인가요?
2. 세 상품의 1개당 이익과 이익률은 얼마인가요?
3. 커피만 판다고 할 때, 월 최소 판매량은 몇 잔인가요? 월 순수익 500,000원을 더 남기려면 몇 잔인가요?
4. 판매 비중이 커피 60% : 샌드위치 25% : 디저트 15%라면, 평균 1개당 이익과 월 최소 판매량(상품별 수량 포함)은 얼마인가요?

## 무엇을 설명하는 사례인가

고정비를 생활비까지 포함해 합산하고, 그 합계를 1개당 이익으로 나누면 "한 달에 최소 몇 개를 팔아야 하는가"가 나온다는 것을 보여준다. 이 식은 CH13의 손익분기 판매량(고정비 ÷ 단위당 공헌이익)과 같은 구조다.

## 계산 과정

1. 생활 필요 고정비 = 700,000 + 600,000 + 250,000 + 300,000 + 100,000 + 150,000 + 100,000 = **2,200,000원**
   사업 필요 고정비 = 1,200,000 + 1,800,000 + 250,000 + 300,000 + 150,000 = **3,700,000원**
   총 고정비 = **5,900,000원**. 생활 필요 고정비 비중 = 2,200,000 ÷ 5,900,000 = **약 37.3%**
2. 1개당 이익 = 판매가 − 1개당 변동비

| 상품 | 1개당 이익 | 이익률 |
|---|---|---|
| 커피 | 5,000 − 2,000 = **3,000원** | 60.0% |
| 샌드위치 | 7,500 − 3,100 = **4,400원** | 58.7% |
| 디저트 | 6,000 − 2,100 = **3,900원** | 65.0% |

3. 월 최소 판매량 = 5,900,000 ÷ 3,000 = 1,966.7 → **1,967잔** (올림). 순수익 목표를 더하면 (5,900,000 + 500,000) ÷ 3,000 = 2,133.3 → **2,134잔** (올림).
4. 평균 1개당 이익 = 0.60×3,000 + 0.25×4,400 + 0.15×3,900 = 1,800 + 1,100 + 585 = **3,485원**
   월 최소 판매량 = 5,900,000 ÷ 3,485 = 1,692.97 → **1,693개**. 비중대로 나누면 커피 약 1,016개, 샌드위치 약 423개, 디저트 약 254개이다.

## 해석

- 이 수량은 고정비를 겨우 메우는 "최소" 목표이며, 성장을 위해서는 더 높은 목표가 필요하다.
- 생활 필요 고정비를 사업 고정비에 넣는 것은 소상공인의 현실 목표를 정하기 위한 워크숍의 방식이며, 회계상 비용 처리와는 구분해서 읽어야 한다.
