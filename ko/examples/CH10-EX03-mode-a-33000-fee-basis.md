# CH10-EX03. 33,000원 상품의 매출총이익과 공헌이익

- 관련 Chapter: CH10. MODE A — 현재가격 진단
- 관련 MN/KM: MN06 / KM044~KM046

## 생각해 보기

〔실습용 가상자료〕 VAT 포함 판매가 33,000원(VAT율 10%)인 상품이 있다. 직접원가는 9,800원이다. 변동비는 결제 수수료(실지급액의 2.8%)와 택배비 3,200원이다.

1. VAT 제외 순매출은 얼마인가?
2. 매출총이익과 매출총이익률은 얼마인가?
3. 변동비 합계는 얼마이고, 결제 수수료는 어느 금액을 기준으로 계산하는가?
4. 공헌이익과 공헌이익률은 얼마인가? 매출총이익률과 비교하면 어떤 차이가 보이는가?

<details>
<summary>정답과 풀이 보기</summary>

1. 순매출 = 33,000 ÷ 1.10 = 30,000원.
2. 매출총이익 = 30,000 − 9,800 = 20,200원. 매출총이익률 = 20,200 ÷ 30,000 = 67.3%.
3. 수수료는 실지급액(33,000원) 기준이므로 33,000 × 2.8% = 924원이다. 변동비 합계 = 924 + 3,200 = 4,124원.
4. 공헌이익 = 20,200 − 4,124 = 16,076원, 공헌이익률 = 16,076 ÷ 30,000 = 53.6%. 매출총이익률 67.3%보다 13.7%p 낮다. 판매·배송 변동비를 뺐기 때문이며, 이 상품을 이 채널로 파는 것이 얼마나 남는지는 공헌이익이 말해 준다.

- 무엇을 설명하는 사례인지: 입력 정리(VAT 포함 여부, 수수료의 기준)를 먼저 맞춘 뒤 MODE A의 두 지표를 순서대로 구하는 사례. 같은 상품을 CH11-EX02(목표가격 역산)와 CH12-EX02(허용원가 역산)에서 이어서 쓴다.

</details>
