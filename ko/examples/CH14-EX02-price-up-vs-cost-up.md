# CH14-EX02. 가격 +10% 대 직접원가 +10% 시나리오 비교

- **관련 Chapter**: CH14. Scenario Compare — 시나리오 비교 (§10 심화)
- **관련 Tool**: Scenario Compare (`run_scenario_compare`). 이 사례는 같은 식을 손으로 계산한다.
- **출처**: 표준강의안 3-1-09 (사례 종합 실습, 문제 1·4·5). 교육용 가상자료〔실습용 가상자료〕이며 실제 기업 데이터가 아니다. 기준선은 CH13-EX03과 같다.

## 입력값 (기준선)

| 항목 | 값 |
|---|---|
| 판매가 | 33,000원 (VAT 10% 포함) |
| 직접원가 | 9,800원 |
| 결제 수수료 | 실지급액의 2.8% (가격이 바뀌면 함께 바뀐다) |
| 택배비 | 3,200원 |
| 월 고정운영비 | 1,200,000원 |

시나리오 S1은 판매가만 10% 올려 36,300원으로, 시나리오 S2는 직접원가만 10% 올려 10,780원으로 바꾼다. 나머지는 모든 시나리오가 같다.

## 문제

1. 기준선의 순매출, 공헌이익, 공헌이익률, 손익분기 수량을 구하세요.
2. S1과 S2 각각의 같은 네 값과, 기준선 대비 델타 네 가지를 구하세요.
3. 어느 쪽이 더 "아픈가"를 숫자로 말할 수 있나요? Scenario Compare가 이 질문에 답해 주나요?

## 계산 과정

```
기준선  N = 30,000   변동비 = 33,000×2.8% + 3,200 = 4,124
        CM = 30,000 − 9,800 − 4,124 = 16,076 (53.6%)    Q_BEP = 1,200,000 / 16,076 ≈ 74.6
S1      N = 36,300 / 1.1 = 33,000   변동비 = 36,300×2.8% + 3,200 = 4,216.4
        CM = 33,000 − 9,800 − 4,216.4 = 18,983.6 (57.5%)    Q_BEP ≈ 63.2
S2      N = 30,000   변동비 = 4,124
        CM = 30,000 − 10,780 − 4,124 = 15,096 (50.3%)       Q_BEP ≈ 79.5
```

| 델타 (기준선 대비) | S1 (가격 +10%) | S2 (직접원가 +10%) |
|---|---|---|
| `net_sales_ex_vat_delta` | +3,000 | 0 |
| `contribution_margin_delta` | +2,907.6 | −980 |
| `contribution_margin_rate_delta` | 약 +3.9%p | 약 −3.3%p |
| `break_even_quantity_delta` | 약 −11.4개 | 약 +4.8개 |

## 해석

- S1에서 순매출은 3,000원 늘지만 공헌이익은 2,907.6원만 늘어난다. 결제 수수료가 실지급액에 비례해 같이 커지기 때문이다. 가격을 올릴 때는 가격에 비례하는 비용도 함께 바뀐 값으로 계산해야 델타가 맞다.
- S2는 순매출 델타가 0이지만 공헌이익과 손익분기는 나빠진다. 델타 0은 "아무것도 안 바뀌었다"가 아니라 그 지표가 바뀐 필드와 무관하다는 뜻일 수 있다(CH14 §7).
- 같은 10%라도 방향이 반대이고 크기도 다르다. 가격 +10%는 손익분기를 약 11.4개 줄이고, 원가 +10%는 약 4.8개 늘린다.
- Scenario Compare는 어느 쪽이 나은지 추천하지 않는다. 가격을 10% 올렸을 때 판매량이 그대로일지는 이 계산이 다루지 않는 가정이며(시나리오는 `planned_quantity`를 바꾸지 않는다), 수량이 달라질 때의 손익은 계획 판매량을 바꿔 Volume Profit(CH13)을 따로 실행해야 한다.
