# CH14-EX03. 가격 3안 비교 — 비누 세트의 손익분기와 영업이익

- **관련 Chapter**: CH14. Scenario Compare — 시나리오 비교 (§10 심화), CH13
- **관련 Tool**: Scenario Compare (손익분기 비교), Volume Profit (영업이익, CH13). 이 사례는 같은 식을 손으로 계산한다.
- **출처**: 표준강의안 3-1-02 (MODE A·B·C·손익분기·시나리오·가격 검증, 실습③). 교육용 가상 사례〔실습용 가상자료〕이며 실제 업종 값이 아니다.

## 입력값

| 항목 | 값 |
|---|---|
| 상품 | 핸드메이드 비누 3개입 세트 |
| 판매가 안 | 15,000원 / 18,000원 / 21,000원 (모두 VAT 10% 포함) |
| 직접원가 | 5,500원 |
| 채널 수수료 | 순매출의 8% |
| 결제 수수료 | 실지급액(판매가)의 3% |
| 택배비 | 3,000원 |
| 월 고정운영비 | 400,000원 |
| 계획 판매량 | 월 180세트 (세 안 모두 같게 둔다) |

원가·수수료율·고정비는 그대로 두고 가격만 바꾼다. 수수료는 가격에 비례하므로 안마다 금액이 달라진다.

## 문제

1. 가격 안마다 공헌이익, 공헌이익률, 손익분기 수량, 월 180세트의 영업이익, 안전한계(수량)를 구하세요.
2. 영업이익이 가장 큰 안을 고르면 되나요? 이유를 쓰세요.
3. 18,000원 안에서 180세트로 얻는 영업이익을 다른 두 가격에서도 얻으려면 월 몇 세트를 팔아야 하나요? (이 수량을 "유지 판매량"이라 부르자.)

## 계산 과정

```
N = P / 1.1
변동비 = N×8% + P×3% + 3,000
CMu = N − 5,500 − 변동비
Q_BEP = 400,000 / CMu
영업이익 = CMu × 180 − 400,000
안전한계 = 180 − Q_BEP
유지 판매량 = (400,000 + 682,618) / CMu     (18,000원 안의 영업이익 682,618원을 기준)
```

| 항목 | 15,000원 | 18,000원 | 21,000원 |
|---|---|---|---|
| 순매출(N) | 13,636.36 | 16,363.64 | 19,090.91 |
| 변동비 | 4,540.91 | 4,849.09 | 5,157.27 |
| 공헌이익 | 3,595.45 | 6,014.55 | 8,433.64 |
| 공헌이익률 | 26.4% | 36.8% | 44.2% |
| 손익분기 수량 | 111.3세트 | 66.5세트 | 47.4세트 |
| 월 180세트 영업이익 | 247,182 | 682,618 | 1,118,055 |
| 안전한계(수량) | 68.7세트 | 113.5세트 | 132.6세트 |
| 유지 판매량 | 301.1세트 | 180.0세트 | 128.4세트 |

## 해석

- 같은 180세트라면 가격이 높을수록 영업이익이 크다. 그러나 "21,000원이 정답"은 아니다. 가격이 올라도 판매량이 같다는 가정 자체가 검증 대상이다.
- 유지 판매량이 이 가정을 거꾸로 읽게 해 준다. 15,000원으로 내리면 같은 영업이익을 위해 약 301세트(약 1.7배)가 필요하고, 21,000원이면 약 128세트까지 줄어도 같은 영업이익이다. 가격을 올리는 안은 "판매량이 얼마나 줄어도 버티는가"를, 내리는 안은 "판매량이 얼마나 늘어야 하는가"를 묻는 질문이 된다.
- 손익분기 수량은 Scenario Compare의 델타로 읽을 수 있지만, 영업이익과 유지 판매량은 수량을 입력으로 받는 계산이므로 Volume Profit(CH13)을 안마다 따로 실행해 얻는다(CH14 §6).
- 수요 반응은 계산이 아니라 가정이다. 어느 가격의 수량 가정을 시장에서 확인할지는 CH15의 검증설계로 이어진다.
