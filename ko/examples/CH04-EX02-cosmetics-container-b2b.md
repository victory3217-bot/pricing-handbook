# CH04-EX02. 화장품 용기 B2B 대량발주 사례

- 관련 Chapter: CH04. 채널과 고객관계가 바꾸는 가격구조
- 관련 MN/KM: MN06 / KM048
- 무엇을 설명하는 사례인지: B2B 거래에서 대량발주 물량이 단가와 마진 구조를 바꾸고, 중간 유통단계를 줄인 직접 제안영업으로 수수료를 낮춘 사례.

## 내용

화장품 용기 B2B 사례에서는 공식 납품가격과 대량발주 기준 실판매가가 다르다. 20만 개 수준의 발주가 확보될 때 단가를 낮추면서도 약 25%의 마진을 유지할 수 있도록 설계했고, 대량생산을 통한 규모의 경제가 핵심 전제가 되었다. 중간 유통단계를 줄이고 화장품 제조사에 직접 제안영업을 하여 수수료를 낮췄다.

출처: 『가격이 전략이다』, pp. 208-215.
