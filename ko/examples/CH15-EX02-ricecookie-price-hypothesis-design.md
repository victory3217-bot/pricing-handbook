# CH15-EX02. 가격가설 한 문장과 검증설계 네 칸 쓰기 — 쌀쿠키 18,000원 인상 안

- **관련 Chapter**: CH15. 가격가설의 검증과 의사결정 (§10 심화)
- **관련 Tool**: 없음 (Pricing Harness에는 검증 데이터를 저장하는 기능이 없다. CH15 §6). 숫자 근거만 MODE A·BEP·Volume Profit과 같은 식으로 계산한다.
- **출처**: 표준강의안 3-1-02 (실습④)와 3-1-12 (실습⑤)가 사용한 쌀쿠키 사례. 교육용 가상 사례〔실습용 가상자료〕이며 실제 상품·채널 조건이 아니다.

## 상황

수제 쌀쿠키 6개입 세트(가상)를 현재 15,000원(VAT 포함)에 팔고 있다. 직접원가 6,000원, 택배 3,000원, 수수료는 실지급액의 5%, 월 고정운영비는 600,000원이다. 가격을 18,000원으로 올리는 안을 검토한다. 현재 가격에서 월 250세트를 팔면 영업이익은 약 371,591원이다.

## 문제

1. 이 인상 안을 참/거짓을 구분할 수 있는 가격가설 한 문장으로 쓰세요.
2. 계산으로 확정되는 숫자와 시장에서만 확인되는 가정을 나누어 적으세요.
3. 검증설계 네 칸(조사검증대상, 측정지표와 판단 기준, 방법·대상·기간, 피드백데이터)을 쓰세요. 기준 숫자는 직접 정합니다.
4. 네 칸이 연결되어 있는지 점검하세요.

<details>
<summary>정답과 풀이 보기</summary>

정답은 하나가 아니다. 아래는 하나의 예시이며, 기준이 되는 숫자는 사업마다 직접 정해야 한다(CH15 §4).

## 1. 가격가설

"지금 고객은 18,000원에도 구매할 것이다."

## 2. 계산과 가정의 구분

| 구분 | 내용 | 성격 |
|---|---|---|
| 공헌이익 | 15,000원에서 3,886.36원 → 18,000원에서 6,463.64원 | 계산 |
| 손익분기 수량 | 약 154.4세트 → 약 92.8세트 | 계산 |
| 같은 영업이익에 필요한 수량 | 15,000원·250세트의 영업이익 371,591원은 18,000원에서 약 150세트로 거의 같아진다(18,000원·150세트: 369,545원) | 계산 |
| 18,000원에서 월 150세트 이상이 팔린다 | 고객이 인상된 가격에서도 구매한다는 가정 | **가정** (검증 대상) |

계산은 "수량이 얼마나 줄어도 되는가"까지 알려 준다. "실제로 얼마나 줄어드는가"는 시장에서만 알 수 있다.

## 3. 검증설계 예시

| 칸 | 예시 |
|---|---|
| 조사검증대상 | 기존 구매 고객이 18,000원에도 구매하는가 |
| 측정지표와 판단 기준 | 인상 가격에서의 월 판매량. 판단 기준은 직접 정한다(예: 계산상 영업이익이 비슷해지는 150세트 이상이면 유지, 그 아래면 수정 또는 폐기). 150세트는 계산에서 나온 기준이며 통계적 기준이 아니다 |
| 방법·대상·기간 | 전체 고객이 아닌 한 채널·한 세그먼트에서, 되돌릴 수 있는 규모로 일정 기간 시험 판매 |
| 피드백데이터 | 판매량, 할인 요구, 거절 사유를 기록하고, 가격이 아닌 다른 가정(원가·가치·채널)을 다시 열어야 하는지 판단하는 근거로 쓴다 |

## 4. 연결 점검

- 측정지표가 실제로 관찰·기록 가능한가: 월 판매량은 기록할 수 있다.
- 판단 기준(유지/수정/폐기)이 있는가: 위 예시는 숫자 기준 하나로 갈라 준다.
- 작고 되돌릴 수 있는 실험인가: 한 채널·한 세그먼트로 한정했다.
- 검증 기록은 현재 도구에 저장 기능이 없으므로 워크시트 같은 별도 문서에 남긴다(CH15 §6).
